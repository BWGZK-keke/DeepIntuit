## Overview

**DeepIntuit** is a progressive framework for **open-instance video classification** that evolves models from simple imitation to intrinsic reasoning.

Instead of directly predicting labels from videos, DeepIntuit introduces a **three-stage reasoning pipeline**:

1. **Cold-start supervised alignment**  
   Initializes the reasoning capability of the model using reasoning traces generated by a teacher model.

2. **Intrinsic reasoning refinement (Stage 1)**  
   Reinforces reasoning ability using **Group Relative Policy Optimization (GRPO)**.

3. **Intuitive calibration (Stage 2)**  
   Trains a classifier on reasoning traces generated by the refined reasoning model to produce stable predictions.

This design decouples reasoning generation from final decision making, improving robustness and generalization in open-instance video classification tasks.

# Installation

The repository contains **separate environments for each stage**.

Install the dependencies for each stage using the corresponding `requirements.txt`.

```bash
# clone repository
git clone https://github.com/BWGZK-keke/DeepIntuit.git
cd DeepIntuit
````

### Cold-start environment

```bash
cd coldstart
pip install -r requirements.txt
```

### Stage 1 environment

```bash
cd stage1_model
pip install -r requirements.txt
```

### Stage 2 environment

```bash
cd stage2_model
pip install -r requirements.txt
```

Pretrained checkpoints are available on HuggingFace:

[https://huggingface.co/BWGZK/DeepIntuit](https://huggingface.co/BWGZK/DeepIntuit)

Download the checkpoints and place them in your local directory.

Ensure the **model configuration matches the provided checkpoint** before running inference or training.

# Training Pipeline

DeepIntuit follows a **three-stage training process**.

You must run the stages **in the following order**.

---

## Stage 0 — Cold-Start Alignment

Initialize reasoning capability with supervised reasoning traces.

```bash
cd coldstart
bash cold_start_train.sh
```

This stage produces the **initial reasoning model**.

---

## Stage 1 — Intrinsic Reasoning Refinement

Refine the reasoning model using **GRPO reinforcement learning**.

```bash
cd stage1_model
bash train_stage1_smarthome.sh
```

This stage produces a **refined reasoning model** capable of generating higher-quality reasoning traces.

---

## Stage 2 — Intuitive Calibration

Train a classifier on reasoning traces generated by the Stage-1 model.

```bash
cd stage2_model
bash stage2_train_smarthome.sh
```

This produces the **final DeepIntuit model** used for inference.

---

# Inference

After training Stage 2 (or downloading the pretrained checkpoint), run inference:

```bash
cd stage2_model
python inference.py \
  --model_path path_to_checkpoint \
  --video_path path_to_video
```

Make sure:

* the checkpoint is correctly loaded
* the model configuration matches the checkpoint
